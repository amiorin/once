# Add R2 backend (Cloudflare R2)

Mirror the existing S3 backend wiring for Cloudflare R2. R2 is S3-compatible,
so OpenTofu still uses `backend "s3"` — but with a custom endpoint, `region =
"auto"`, and skip flags. All R2 params use the `r2-` prefix.

## Decisions

- Template params: `r2-bucket`, `r2-endpoint` (full URL, e.g.
  `https://<account-id>.r2.cloudflarestorage.com` or
  `https://<account-id>.eu.r2.cloudflarestorage.com` for EU jurisdiction
  buckets; region hardcoded to "auto"). The endpoint is supplied directly
  rather than derived from an account-id, so jurisdictioned buckets (`.eu`,
  `.fedramp`) work without code changes.
- Credentials: `r2-access-key-id` + `r2-secret-access-key` rendered inline as
  `access_key` / `secret_key` in `backend.tf`. The rendered file lands in
  `.dist/` (gitignored). Users supply them via `BC_PAR_R2_ACCESS_KEY_ID` and
  `BC_PAR_R2_SECRET_ACCESS_KEY`.
- Validation: require `aws` CLI (same as S3). Credential probe runs
  `aws s3api head-bucket --bucket <r2-bucket> --endpoint-url <r2-endpoint>`
  with `AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` injected into the
  subprocess env from the params. `head-bucket` is used instead of
  `list-buckets` because the latter requires an Admin-scoped R2 token,
  whereas `head-bucket` works with Object Read & Write tokens. Stderr from a
  failed call is pattern-matched to distinguish missing-bucket (`(404)` /
  `Not Found` / `NoSuchBucket`) from bad credentials (`(401)` / `(403)` /
  `Forbidden` / `InvalidAccessKey` / `SignatureDoesNotMatch`); anything else
  is reported verbatim. The four R2 string params are also schema-required
  to be non-empty, with a defense-in-depth check in `r2-errors` that emits
  an explicit "missing credentials" error if they slip through.
- Profile wiring: switch `website`, `online`, `space` from `s3` to `r2`. Keep
  the `s3` def in place (still a valid backend choice).

## Files

### New

- `src/resources/io/github/bigconig-ai/once/tools/tofu-backend/r2/backend.tf`

  ```hcl
  terraform {
    backend "s3" {
      bucket     = "<{ r2-bucket }>"
      key        = "<{ target-object }>.tfstate"
      region     = "auto"
      access_key = "<{ r2-access-key-id }>"
      secret_key = "<{ r2-secret-access-key }>"
      endpoints = {
        s3 = "<{ r2-endpoint }>"
      }
      skip_credentials_validation = true
      skip_metadata_api_check     = true
      skip_region_validation      = true
      skip_requesting_account_id  = true
      use_path_style              = false
    }
  }
  ```

### Changed

- `src/clj/io/github/bigconig_ai/once/options.clj`
  - New `^:private r2` def with the four r2 params.
  - `website`, `online`, `space` use `r2` in place of `s3`.

- `src/clj/io/github/bigconig_ai/once/validation.clj`
  - New `schema:r2` requires `provider-backend = "r2"` plus non-empty
    `:r2-bucket`, `:r2-endpoint`, `:r2-access-key-id`, `:r2-secret-access-key`
    (via a shared `non-empty-string` helper).
  - `schema:backend` multi gains `["r2" schema:r2]`.
  - `provider-tools`: `(= provider-backend "r2")` requires `aws`.
  - New `r2-errors` helper invoked from `credential-errors` when
    `provider-backend = "r2"`. Runs `aws s3api head-bucket --bucket <bucket>
    --endpoint-url <r2-endpoint>` with access key/secret injected as env
    vars. Failures are classified by `classify-head-bucket-error` (stderr
    pattern match) into `:missing-bucket`, `:bad-credentials`, or
    `:unknown`, each producing a distinct error message. Extends `run` /
    `cli-check` with optional `:env` overrides to support this.

- `test/clj/io/github/bigconig_ai/once/validation_test.clj`
  - `with-creds` also stubs `:r2-access-key-id` / `:r2-secret-access-key`.
  - `provider-tools-picks-right-clis` gains r2 cases.

- `.envrc.private.example` — commented stubs for `BC_PAR_R2_BUCKET`,
  `BC_PAR_R2_ENDPOINT`, `BC_PAR_R2_ACCESS_KEY_ID`,
  `BC_PAR_R2_SECRET_ACCESS_KEY`.

- `README.md` — mention R2 next to S3 in features and backend env-var section.

- `CLAUDE.md` — note R2 alongside S3 in tofu-backend description.

### Unchanged

- `src/clj/io/github/bigconig_ai/once/tools.clj` — the existing `provider-backend`
  transform already routes to the right template directory.
